Space Explorer Website (Frontend)
A modern space-themed website built using React.
This project includes multiple pages like Home, Login, Signup, Explore, Missions, and Community with a sticky navbar and smooth navigation using React Router.

## Features

✔ Sticky navbar (visible on all pages)
✔ Home page with space background
✔ Login & Signup pages
✔ Explore page with planet cards
✔ Missions page with mission details
✔ Community page
   1.Everyone can see posts
   2.Only logged-in users can comment (frontend logic)
✔ Fully frontend (no backend)
✔ Responsive UI

## Tech Stack
1.React
2.React Router DOM
3.CSS
4.Vite
